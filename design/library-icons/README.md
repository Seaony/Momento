# 图库图标

用户给每个图库选的图标。Codex 画，一张一次调用，提示词在 `第1批/prompts/`（公共段保证整套风格一致，后面只换物件和背景色）。

- 风格：和 App 图标同一路的哑光软陶 3D，单一色相的竖向渐变底，中间一个圆润物件，不画脸。
- 24 个，按编号排在图标网格里（应用图标作为默认放第一格，正好 5 × 5）：风景、海洋、自然、花卉、天空、夜景、城市、建筑、旅行、人像、人文、美食、宠物、艺术、设计、摄影、时尚、家居、交通、运动、音乐、游戏、灵感、收藏。
- 第 1 批里运动（网球配黄绿底）和灵感（灯泡配黄底）对比太弱，换了背景色重画；旧图在 `第1批/旧版/`。
- 应用里用的是缩到 128 像素的版本，放在 `app/resources/library-icons/<编号>.png`，`momento.png` 是默认的应用图标。改了这里的图，重新缩放后复制过去。

抽出来的大图只留本地、不进仓库。
