# 图库图标

用户给每个图库选的图标。Codex 画，一张一次调用。现在用的是 `第3批/`（2026-11-22），提示词在 `第3批/prompts/`。

- 风格：和应用图标 M06 仓鼠同一路（照 `design/app-icon/第4批` 的原提示词，附第 3 批 E02、F01 作参考），每张一只拿着色卡的小动物，表情只用可爱、自然的，底色各不相同。
- 24 个，按编号排在图标网格里（应用图标作为默认放第一格，正好 5 × 5）。编号是第 1 批物件图标时定的，已经存进用户图库，所以不改，只换图和显示名：mountain 柴犬、wave 猫咪、tree 兔子、flower 狐狸、cloud 水獭、moon 企鹅、city 考拉、landmark 熊猫、travel 刺猬、portrait 变色龙、culture 猫头鹰、food 青蛙、pet 海豹、art 小鸡、design 小羊、camera 浣熊、fashion 松鼠、interior 小熊、car 树懒、sport 小鹿、music 小猪、game 六角恐龙、idea 柯基、heart 羊驼。
- 第 1 批：哑光软陶 3D 物件（山、浪、相机……），换成仓鼠图标后用户嫌丑。第 2 批：厚羊毛毡物件，被否，用户要的是 logo 那样的角色图。
- 第 1 批里运动（网球配黄绿底）和灵感（灯泡配黄底）对比太弱，换了背景色重画；旧图在 `第1批/旧版/`。
- 应用里用的是缩到 128 像素的版本，放在 `app/resources/library-icons/<编号>.png`，`momento.png` 是默认的应用图标。改了这里的图，重新缩放后复制过去。

抽出来的大图只留本地、不进仓库。
