# 内置字体

- Inter 4.1：官方发布包 `https://github.com/rsms/inter/releases/tag/v4.1`，仅保留 Regular 400、Medium 500、SemiBold 600、Bold 700；分别供正文、框架表单标签、分组标题及强调标题使用。
- Geist Mono Regular 400：官方 `https://github.com/vercel/geist-font/tree/main/fonts/GeistMono/ttf`，用于数量、尺寸、日期、文件大小等数值。

原始 SIL Open Font License 分别保存在 `Inter-OFL.txt`、`GeistMono-OFL.txt`，随字体一起内置。字体文件未修改。中文、日文由各平台系统字体回退，不打包 CJK 字体。
