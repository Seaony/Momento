# Changelog

## 1.1.0

- New app icon: a sleeping felt hamster. The accent color is now blue, and the light theme uses neutral grays.
- Ratings and image annotations have been removed. Tags, folders and notes stay as they were.
- Fixed data-safety issues found in a full code review.
- Large libraries are faster: importing folders, paging through Recents, sidebar filters, auto-import scanning and batch rename.
- Animated images share one decoding budget, so a page full of GIFs no longer stalls everything else.
- Fixes for Live Photo pairing, auto-import retries and counts, drag-out cleanup and import notifications.
- Works with Momento browser extension 0.3.0, which adds a save button to Xiaohongshu and Instagram posts. Files the extension uploads now have a total size limit.

- 新的应用图标：一只睡着的毛毡仓鼠。主色改成蓝色，浅色主题改用中性灰。
- 去掉了评分和图片区域批注。标签、文件夹和备注不受影响。
- 修复全面代码审查中发现的数据安全问题。
- 大图库更快：导入文件夹、翻看「最近」、侧栏筛选、自动导入扫描和批量重命名。
- 动图共用一份解码额度，满屏 GIF 不再拖慢其他操作。
- 修复实况照片配对、自动导入重试和计数、拖出后的临时文件清理以及导入通知。
- 配合 Momento 浏览器扩展 0.3.0，小红书和 Instagram 的帖子上多了保存按钮。扩展上传的文件有了总大小限制。

## 1.0.1

- The macOS app icon now has rounded corners in the Dock and Finder.

- macOS 的应用图标在 Dock 和访达里改为圆角。

## 1.0.0

First release of Momento for macOS, Windows and Linux.

- Keep images, screenshots, photos and short videos in a `.momento` library on your own disk.
- Browse in masonry, justified rows or list view, preview with Space, and run a full-screen slideshow.
- Organize with nested folders, tags, ratings, notes and smart folders; rename in batches.
- Search and filter by color, tag and format; find similar images and merge them.
- Annotate regions of an image; export originals, JPEG or PNG with saved presets.
- Save images from web pages with the Momento Image Saver browser extension.

第一个版本，支持 macOS、Windows 和 Linux。

- 图片、截图、照片和短视频都存在你自己磁盘上的 `.momento` 图库里。
- 瀑布流、等高行和列表三种视图，空格预览，可以全屏放映。
- 用嵌套文件夹、标签、评分、备注和智能文件夹整理，支持批量重命名。
- 按颜色、标签和格式搜索筛选，查找相似图片并合并。
- 在图上框选区域写批注；导出原图、JPEG 或 PNG，常用设置可以存成预设。
- 配合 Momento Image Saver 浏览器扩展，把网页上的图片直接存进来。
